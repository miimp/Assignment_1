# Assignment_1

This data set contains a list of 20 files from different repositories of canon public domain literary works circa 19thc, containing both female and male authors. All the items, except one were originally written in English (the exeption being The Iliad of Homer, that was published in ancient Greek, and it's also the only item that the date of publication is unkown). 

This dataset serves to access public domain literary works easily that could help students and teachers to develop university projects or just read the texts.

The items included are part of the universal literary canon, around the same period (19thc) and all of them are licenced as public domain works in The Netherlands

Each of the elements was obtained from other GitHub repositories 

The folder contains a Jupyter Notebook to check the dataset, a README file (that serves as an explanation for the repository), a metadata document that collects all the information of each item (title, autho, year of publication, source of the item)

The dataset can be used for research purposes, but also to be able to access literary novels. It should be used to spread interest in literature, and not for financial purposes. 

As all the works included are of Public Domain, so this repository is also of Public Domain.
